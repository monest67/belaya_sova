# Лендинг учебного центра «Белая Сова»

Одностраничный продающий сайт (HTML5 + CSS3 + JS ES6+, без фреймворков).
Mobile First, контрольные разрешения: 320 / 375 / 430 / 768 / 1024 / 1440 / 1920 px.

## Структура проекта

belaya-sova/
├── index.html
├── css/style.css
├── js/script.js
├── images/
│   ├── logo.png      — логотип: белая сова в очках на книгах
│   ├── hero.jpg      — ребёнок паяет схему (первый экран)
│   ├── chemistry.jpg — ребёнок в шляпе с лабораторной посудой (галерея)
│   ├── physics.jpg   — ребёнок паяет схему (галерея)

│   └── science.jpg   — доска с формулами и хим. посуда (галерея)
└── README.md

## Запуск

1. Вариант А: просто открыть index.html в браузере.
2. Вариант Б (рекомендуется): локальный сервер:
   python -m http.server 8000   →   http://localhost:8000

## Что заменить перед публикацией

| Что | Где |
| --- | --- |
| Телефон (3 места) | index.html: шапка, мобильное меню, футер — href="tel:…" и текст |
| Endpoint формы | js/script.js → CONFIG.formEndpoint (POST JSON, поля: name, phone, child, direction, format, comment, consent, meta) |
| Ссылка на отзывы Яндекс Карт | js/script.js → CONFIG.yandexReviewsUrl ИЛИ href кнопки в блоке «Отзывы» (удалить data-placeholder) |
| Ссылки политик и согласия | index.html: футер и чекбокс формы (href) |
| Фото преподавателей | index.html: блок «Преподаватели» — удалить .portrait, вставить <img class="teacher-photo" src="images/teacher-*.jpg"> |
| Реквизиты организации | index.html: футер, блок .footer-legal |
| Тексты отзывов и FAQ | публиковать только после подтверждения центром |

## Примечания

- Пока CONFIG.formEndpoint пуст, форма показывает честное сообщение о неподключённом
  сервисе и НЕ имитирует успешную отправку.
- Пока файлы изображений отсутствуют, вместо них отображается аккуратный плейсхолдер
  с именем файла (атрибут data-fallback). Уберите data-fallback, чтобы отключить.
- Цены (1 000 ₽ / 3 000 ₽ за час) редактируются в одном месте — блок «Форматы и стоимость» в index.html.
- Карта: Яндекс.Карты, точка «Москва, 2-я Миусская улица, 9»; при наличии ключа API
  замените iframe на виджет из конструктора карт.
- Доступность: семантика, label у полей, aria-атрибуты, фокус-стили, prefers-reduced-motion.
- Production: минифицируйте css/style.css и js/script.js, изображения конвертируйте в WebP.
